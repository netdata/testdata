# SNMP Topology Scenario Goldens

This directory contains normalized `netdata.topology.v1` golden payloads for
product-level SNMP topology scenarios.

The scenario source lives in the Netdata Agent repository under
`src/go/plugin/go.d/collector/snmp_topology`. This fixture repository stores only
the bulky full-payload JSON oracle.

The scenario source is Go test code, not raw JSON:

- devices, ports, and relationships are declared in
  `topology_scenario_golden_test.go`;
- raw `ddsnmp` topology metric rows are generated by
  `topology_scenario_builder_test.go`;
- tests feed those generated inputs through the real cache, registry, and
  Function renderer path;
- tests validate the final payload with both the Go topology validator and
  `FUNCTION_TOPOLOGY_SCHEMA.json`;
- tests also run semantic assertions for expected actors, links, evidence, and
  negative contracts.

Fixture data is synthetic:

- private and RFC 5737 documentation IP ranges only;
- locally administered MAC addresses under `02:00:00:*`;
- no SNMP communities, credentials, customer names, real public IPs, or real
  vendor/version `sysDescr` banners.

Regenerate intentionally with:

```bash
cd src/go/plugin/go.d
NETDATA_SNMP_TOPOLOGY_SCENARIO_GOLDEN_DIR=/path/to/netdata-testdata/snmp/topology-scenarios \
  go test -count=1 ./collector/snmp_topology -run TestSNMPTopologyScenarioGoldens -update-snmp-topology-scenario-goldens
```
